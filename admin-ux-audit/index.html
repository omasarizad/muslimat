التغييرات المقترحة للمطور
بطاقات روابط سريعة للصفحة الرئيسية — شبكة بطاقات (٥ في الصف) تربط بكل نوع محتوى متاح. PHP: add_action('welcome_panel',...) الصفحة الرئيسية حالياً فارغة تماماً. المستخدم يدخل ولا يعرف من أين يبدأ. البطاقات تعطيه نظرة عامة فورية على كل ما يمكنه فعله — مثل صفحة رئيسية لتطبيق هاتف. هذا يُطبّق مبدأ Progressive Disclosure: ابدأ بالمفيد.
توجيه تسجيل الدخول — بدلاً من الرئيسية الفارغة، وجّه المستخدم إلى صفحة الدروس مباشرة (كحل مؤقت حتى تُنفّذ بطاقات الرئيسية). add_filter('login_redirect',...) أول ما يراه المستخدم بعد الدخول هو صفحة بيضاء — أسوأ انطباع أول ممكن. التوجيه لقائمة المحتوى يُعطيه سياقاً فورياً.
ألوان الشريط الجانبي — تغيير من الافتراضي إلى رمادي-أزرق داكن (#1e293b) مع لون أخضر (#16a34a) للعنصر النشط. CSS: #adminmenuback { background:#1e293b } التوجه البصري الجديد يستخدم ألوان هادئة ومريحة. أيقونات القائمة تبقى كما هي — التغيير في الألوان فقط. يمكن تعديل اللون ليتماشى مع هوية الموقع.
Taxonomy Order — إخفاء من كل القوائم الفرعية. #adminmenu a[href*="page=to-interface-"] { display:none } صفحة إنجليزية بالكامل مع إعلانات ترويجية ("Did you find this plugin useful?"). وجود صفحة بلغة مختلفة مع إعلانات يكسر ثقة المستخدم بالمنصة.
أدوات — إخفاء من القائمة. remove_menu_page('tools.php') الصفحة فارغة تماماً لهذا الدور. عنصر قائمة يؤدي لصفحة فارغة يُعطي انطباعاً بأن المنصة ناقصة.
WPML → ترجمة النصوص، إعدادات — إخفاء الصفحات الفرعية المحجوبة. remove_submenu_page() هذه الصفحات تُظهر "ليس لديك إذن" عند النقر عليها. لا تعرض ما لا يمكن استخدامه — كل نقرة فاشلة تُحبط المستخدم.
WPML → "الترجمة" PHP: $menu[0] = 'الترجمة' المستخدم يبحث عن وظيفة ("أريد ترجمة محتوى") لا عن اسم منتج تقني. سمّ الأشياء بما تفعله.

التغييرات المقترحة للمطور
عمود المحتوى/المقتطف .column-content { display:none } يعرض أول ٢٠ كلمة بشكل مبتور — لا أحد يقرأ المحتوى من الجدول. المستخدم يفتح المنشور للقراءة الكاملة. هذا العمود يأخذ مساحة عرضية كبيرة ويجعل الجدول مكتظاً.
أعمدة أعلام اللغات (WPML) .column-icl_translations { display:none } يعرض أعلام الدول مع حالة الترجمة في كل صف. إدارة الترجمة لها قسمها الخاص — لا حاجة لتكرارها في كل جدول محتوى.
عمود SEO في الجدول .column-rank_math_seo_details { display:none } يعرض "N/A" في معظم الحالات — لا قيمة معلوماتية فعلية في سياق الجدول. المستخدم الذي يحتاج SEO يصل إليه من داخل صفحة التحرير.
عمود Slug .column-slug { display:none } رمز URL الداخلي — مصطلح تقني لا يحتاجه المستخدم في الجدول. WP يُنشئه تلقائياً من العنوان.
Bulk Actions العلوية .tablenav.top .bulkactions { display:none } الإجراءات المجمّعة (حذف/تعديل مجموعة) ميزة متقدمة. الإبقاء على نسخة واحدة في الأسفل كافٍ لمن يحتاجها.
تكبير الصور المصغرة من ٣٢px إلى ٤٨px مع حواف مستديرة. ٣٢ بكسل صغيرة جداً للتعرف على المحتوى. الصور المصغرة يجب أن تكون مفيدة للتعرف السريع بدون قراءة العنوان.

التغييرات المقترحة للمطور
Rank Math SEO metabox — طيّه (collapsed) افتراضياً بدلاً من إخفائه. JS: document.querySelector('#rank_math_metabox').classList.add('closed') SEO مهم — بعض المستخدمين يحتاجونه. لكن عرضه مفتوحاً بنتيجة "9/100" بلون أحمر يُخيف من لا يعرفه. الحل: اطوِه افتراضياً — من يحتاجه ينقر لفتحه، ومن لا يحتاجه لا يراه.
permalink/slug #edit-slug-box { display:none } حقل URL الداخلي — WP يُنشئه تلقائياً من العنوان. عرضه مع زر "تعديل" يُغري بالتغيير، والتغيير الخاطئ يكسر الروابط.

زر النشر — تكبير + لون أخضر (#16a34a) + عرض أوسع. الإجراء الأهم في الصفحة يجب أن يكون واضحاً ومطمئناً — زر كبير ومميز بدلاً من زر صغير في زاوية.
حقل العنوان — تكبير الخط + حواف مستديرة + تركيز بصري عند النقر. أول حقل يملؤه المستخدم — يجب أن يكون واضحاً ومريحاً.

تغييرات تنطبق على جميع الصفحات
خيارات الشاشة #screen-meta-links { display:none } هذا الزر يكشف لوحة تحكم لإظهار/إخفاء أعمدة وعناصر. نحن نتحكم بالعناصر المعروضة مسبقاً عبر CSS/PHP — لا نريد المستخدم يُعيد تفعيل ما أخفيناه.
مُبدّل اللغة من الشريط العلوي #wp-admin-bar-WPML_ALS { display:none } ضغطه بالخطأ يُحوّل واجهة لوحة التحكم بالكامل للإنجليزية. استرجاعها يتطلب معرفة بمكان الإعداد — مستخدم غير تقني سيتصل بالدعم.
رقم إصدار WordPress #footer-upgrade { display:none } معلومة تقنية ("نسخة 6.6.1") لا تُفيد المستخدم. قد تُثير قلقاً ("هل النسخة قديمة؟ هل يجب تحديثها؟").
حجم الخط العربي — ١٣ → ١٤px + ارتفاع أسطر ١.٤ → ١.٨ WP مصمم للنصوص اللاتينية. النصوص العربية تحتاج مسافة أكبر بين الأسطر بسبب النقاط والتشكيل — بدونها يبدو النص مضغوطاً وصعب القراءة.
الأزرار الأساسية — لون أخضر (#16a34a) + حواف مستديرة (6px). اتساق بصري مع اللون الأساسي للمنصة. يمكن تغيير اللون ليتماشى مع هوية الموقع.
حقول الإدخال — عند التركيز: حدود خضراء + ظل خفيف. إشارة بصرية واضحة تُخبر المستخدم أين يكتب حالياً.

لماذا التوجه البصري الجديد؟

لوحة التحكم الحالية تستخدم ثيم WordPress الافتراضي (رمادي داكن + أخضر غامق) — مصمم للمطورين يقضون ساعات في لوحات التحكم. مستخدمو منصة أعلام مختلفون: يدخلون اللوحة لنشر محتوى ثم يخرجون.

التوجه الجديد يستخدم ألوان هادئة (أخضر #16a34a مع رمادي-أزرق) مع تباعد أوسع وخط عربي أوضح (IBM Plex Sans Arabic) ليشعر المستخدم أنه في بيئة مألوفة ومريحة — ليس في لوحة تحكم تقنية. يمكن تعديل الألوان لتتماشى مع هوية الموقع.

الملخص التنفيذي

لوحة تحكم أعلام مبنية على WordPress مع أنواع محتوى مخصصة (دروس، سلاسل علمية، مقالات، أسئلة وأجوبة، صفحات ثابتة، بودكاست، فوائد، دروس علمية). المستخدمون المستهدفون هم مديرو المحتوى — وكثير منهم لم يستخدموا WordPress سابقاً وليس لديهم خلفية تقنية.

القيود التقنية: لا يمكن إجراء تغييرات هيكلية على HTML. لكن يمكن: تعديلات CSS، إخفاء عناصر، إعادة تسمية، إعادة ترتيب، وتعديلات PHP بسيطة.

ملاحظة: أيقونات الشريط الجانبي تبقى كما هي — التغييرات تشمل الألوان والتسميات والعناصر المخفية فقط.
